Utilities

Present the different utility functions used across the package. We split them into different sections based on how they might be used.

Optimal isometry

To apply an optimal isometry from the optimization routines, we can invoke the apply_optimized_isometry function.

Disentanglers.apply_optimized_isometry — Function
apply_optimized_isometry(opt_isometry, composite_object, left_index, right_index,
                         left_neighbors, right_neighbors)

Apply an optimized isometry tensor to a composite tensor object, verify its unitarity, and return the updated tensor split to match the pre-application setting.

Arguments

  • opt_isometry: The optimized isometry as an ITensor with primed and unprimed combined indices.
  • composite_object: Composite ITensor object on which the isometry is applied.
  • left_index: Left index out of the two indices on which the isometry acts.
  • right_index: Right index out of the two indices on which the isometry acts.
  • left_neighbors: Array of indices representing the left environment.
  • right_neighbors: Array of indices representing the right environment.

Returns

  • The updated composite ITensor after isometry application with the same data structure as pre-application.

See also: isometry_ro_are, isometry_ro_sre, isometry_ts, isometry_ev

Objective functions related

Riemannian optimizers employ objective functions in order to obtain an optimal isometry. We categorize these objective functions into entropy based and overlap based functions.

Entropy

Disentanglers.alpha_renyi_entropy — Function
alpha_renyi_entropy(M, W, composite_tensor_arr, dim_left_index, dim_right_index,
                    dim_left_neighbors, dim_right_neighbors;
                    entropy_pow = 1, δ_ent = 1.0e-8, kwargs...)

Compute the $α$-Rényi entropy associated with the virtual bond shared by the adjacent tensors forming a composite tensor object after the applying an isometry matrix W on manifold M.

Arguments

  • M: Manifold on which W resides.
  • W: Isometry matrix applied to the reshaped composite tensor that has a specific index ordering, (see composite_tensor_arr).
  • composite_tensor_arr: Array representation of the composite tensor with indices ordered as combined_index, followed by combined_left_neighbors and combined_right_neighbors.
  • dim_left_index: Dimension of the left index on which the isometry acts.
  • dim_right_index: Dimension of the right index on which the isometry acts.
  • dim_left_neighbors: Array containing the dimensions of the left neighboring environment indices.
  • dim_right_neighbors: Array containing the dimensions of the right neighboring environment indices.

Keywords

  • entropy_pow = 1: Power $α$ for the Rényi entropy calculation.
  • δ_ent = 1.0e-8: Cutoff threshold for singular values during entropy evaluation.
  • kwargs...: Additional keyword arguments passed to alpha_renyi_cutoff.

Returns

  • The computed $α$-Rényi entropy value.

See also: second_renyi_entropy, alpha_renyi_cutoff

Disentanglers.second_renyi_entropy — Function
second_renyi_entropy(M, W, composite_tensor_arr, dim_left_index, dim_right_index,
                     dim_left_neighbors, dim_right_neighbors; kwargs...)

Compute the second-Rényi entropy ($n = 2$) associated with the virtual bond shared by adjacent tensors forming a composite tensor object after applying an isometry matrix W on manifold M.

Arguments

  • M: Manifold on which the isometry matrix is defined.
  • W: Isometry matrix applied to the reshaped composite tensor.
  • composite_tensor_arr: Array representation of the composite tensor with indices ordered as combined_index, followed by combined_left_neighbors and combined_right_neighbors.
  • dim_left_index: Dimension of the left index on which the isometry acts.
  • dim_right_index: Dimension of the right index on which the isometry acts.
  • dim_left_neighbors: Array containing the dimensions of the left neighboring environment indices.
  • dim_right_neighbors: Array containing the dimensions of the right neighboring environment indices.

Keywords

  • kwargs...: Additional keyword arguments (reserved for future extensions).

Returns

  • The computed second-order Rényi entropy value ($- \log \text{Tr}(\rho^2)$), equivalent to alpha_renyi_entropy at alpha=2.

See also: alpha_renyi_entropy

Overlap/Distance measures

Disentanglers.unitary_overlap — Function
unitary_overlap(M, W, composite_tensor_arr, raw_ref_op_dag, site_i,
                dim_left_index, dim_right_index, dim_left_neighbors,
                dim_right_neighbors; kwargs...)

Computes the unitary overlap (or infidelity/distance measure) between a target tensor network and a reference operator daggered, after applying a linear operator or matrix W to the active site's composite tensor.

Arguments

  • M: Manifold on which W resides.
  • W: Linear operator/matrix applied to the combined site tensor components.
  • composite_tensor_arr: Array representation of the composite tensor with indices ordered as combined_index, followed by combined_left_neighbors and combined_right_neighbors.
  • raw_ref_op_dag: Vector of reordered raw tensors representing the reference operator's adjoint chain.
  • site_i: The site index indicating the starting position of the two-site operator.
  • dim_left_index: Dimension of the left index on which the isometry acts.
  • dim_right_index: Dimension of the right index on which the isometry acts.
  • dim_left_neighbors: Array containing the dimensions of the left neighboring environment indices.
  • dim_right_neighbors: Array containing the dimensions of the right neighboring environment indices.
  • kwargs...: Additional keyword arguments passed to underlying optimization or norm functions.

Returns

  • A floating-point value representing 1 - (1 / 2^n) * real(normalized_Frobenius_norm_opt(up_composite_tensor_arr, raw_ref_op_dag, site_i), where n is the length of raw_ref_op_dag and norm is computed via normalized_Frobenius_norm_opt, see Disentanglers.normalized_Frobenius_norm_opt.

State overlap

Disentanglers.permute_state_and_return_raw_data — Function
permute_state_and_return_raw_data(psi, set_dag)

Permute the site and link indices of a Matrix Product State (MPS) psi into a standardized canonical order across all tensors and extract their raw multi-dimensional array data.

Arguments

  • psi: The Matrix Product State (MPS) object from ITensors.jl.
  • set_dag: Boolean flag; if true, takes the conjugate/dagger (dag) of the state before processing.

Returns

  • A Vector{Array} containing the raw tensor array data for each site in the MPS, properly permuted along their link and site indices.

See also: inner_custom

Dispatch and compute a custom inner product between psi_p_arr and eta_dag_p_arr while taking into consideration the already contracted two-site tensor at position i and i+1 in psi_p_arr.

Returns

  • The result of the custom inner product contraction for the specified boundary or bulk region.

Disentanglers.permute_op_and_return_raw_data — Function
permute_op_and_return_raw_data(op, set_dag)

Permutes the indices of a Matrix Product Operator (MPO) or similar tensor network operator into a standard canonical site-index ordering and extracts its raw underlying tensor data as a vector of standard Arrays.

Arguments

  • op: An MPO or tensor network operator (typically from ITensors.jl).
  • set_dag: A boolean (Bool) flag. If true, the adjoint (dagger/conjugate transpose) of the operator is taken via dag(op) before processing.

Returns

  • Vector{Array}: A vector containing the raw dense array data extracted from each tensor in the permuted operator chain.

normalized_Frobenius_norm_opt(two_site_arr_dc, raw_ref_op_dag, i)

Compute a normalized Frobenius norm or optimized overlap contraction for a two-site tensor acting on neighboring sites i and i + 1 against a reordered raw reference operator chain.

Arguments

  • two_site_arr_dc: Raw array data of the two-site tensor (deep-copied internally for safe manipulation).
  • raw_ref_op_dag: Vector of reordered raw tensors representing the reference operator's adjoint chain.
  • i: Integer site index indicating the starting position of the two-site operator.

Returns

  • The scalar contraction result representing the normalized norm/overlap value.

Entropy functions

Disentanglers.alpha_renyi_cutoff — Function
alpha_renyi_cutoff(S, a, δ; renormalize = false, kwargs...)

Compute the $lpha$-Rényi entropy from a spectrum of singular values S using a cutoff threshold δ to filter out negligible contributions.

Arguments

  • S: Spectrum of singular values (can be an array, vector, or ITensor spectrum object).
  • a: Power parameter $α$ for the Rényi entropy (supports $α$ = 1 for von Neumann entropy).
  • δ: Cutoff threshold below which singular values are ignored.

Keywords

  • renormalize = false: Boolean flag to normalize the singular value spectrum before entropy calculation.
  • kwargs...: Additional keyword arguments (reserved for compatibility).

Returns

  • The computed $α$-Rényi entropy value.
