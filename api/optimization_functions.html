Riemannian based disentanglers

Disentanglers.isometry_ro_are — Function
isometry_ro_are(composite_object, left_index, right_index, left_neighbors, right_neighbors;
                gradient_free_solver = false, entropy_pow = 1, δ_ent = 1.0e-8,
                renormalize = false, manifold = Stiefel, manifold_field = ℂ,
                opt = quasi_Newton, initial_p0 = "RS", p0_val = nothing, kwargs...)

Return the optimized isometry that minimizes the $α$-Rényi entropy of a composite tensor network object across the specified cut.

Note

This function is designed to be used in conjunction with apply_optimized_isometry in order to return to the original form. See examples Disentangling the MPS, Compressing the MPO, Optimizing the LPDO.

Arguments

  • composite_object: Composite ITensor object on which the isometry acts.
  • left_index: Left index out of the two indices on which the isometry acts.
  • right_index: Right index out of the two indices on which the isometry acts.
  • left_neighbors: Array of indices that end up on the left after the SVD cut.
  • right_neighbors: Array of indices that end up on the right after the SVD cut.

Keywords

  • gradient_free_solver = false: Boolean flag to toggle gradient-free optimization solvers.
  • entropy_pow = 1: Power $α$ for the Rényi entropy as the objective function.
  • δ_ent = 1.0e-8: Cutoff threshold for singular values.
  • renormalize = false: Flag indicating whether to renormalize the singular values post application of SVD.
  • manifold = Stiefel: Manifold constructor for optimization (e.g., Stiefel, can also be Unitary, Grassmannian).
  • manifold_field = ℂ: Number field type over which the manifold is defined (defaults to Complex, ℂ but can also be Real, ℝ field).
  • opt: The optimization solver function (default: quasi_Newton).
  • initial_p0 = "RS": Strategy for initial point generation ("RS": Random Split, "RE": Random Entangled, "I": Identity, or "C": Custom).
  • p0_val = nothing: Custom initial matrix on the manifold value if initial_p0 = "C".
  • kwargs...: Additional keyword arguments passed to the underlying solver or entropy evaluation functions.

Returns

  • u_kij: Optimized isometry as an ITensor with primed and unprimed combined indices.
  • res: Final solver state or result object.
  • initial_objective_val: Initial objective value before optimization.
  • final_objective_val: The final objective function value evaluated using the optimized solver result.
  • elapsed_time: Total execution time for the optimization process in seconds.

See also: isometry_ro_sre, isometry_ts

Disentanglers.isometry_unitary_overlap — Function
isometry_unitary_overlap(composite_object, raw_ref_op_dag, site_i,
                         left_index, right_index, left_neighbors, right_neighbors;
                         gradient_free_solver = false, manifold = Stiefel,
                         manifold_field = ℂ, opt = quasi_Newton,
                         initial_p0 = "RS", p0_val = nothing, kwargs...)

Optimizes an isometry/unitary transformation over a manifold to minimize the distance with a reference operator adjoint for a composite tensor network site.

Note

This function is designed to be used in conjunction with apply_optimized_isometry in order to return to the original form. See examples Compressing the MPO.

Arguments

  • composite_object: Composite ITensor object on which the isometry acts.
  • raw_ref_op_dag: Vector of reordered raw tensors representing the reference operator's adjoint chain.
  • site_i: The site index indicating the starting position of the two-site operator.
  • dim_left_index: Dimension of the left index on which the isometry acts.
  • dim_right_index: Dimension of the right index on which the isometry acts.
  • dim_left_neighbors: Array containing the dimensions of the left neighboring environment indices.
  • dim_right_neighbors: Array containing the dimensions of the right neighboring environment indices.

Keyword Arguments

  • gradient_free_solver = false: Boolean flag to toggle gradient-free optimization solvers.
  • manifold = Stiefel: Manifold constructor for optimization (e.g., Stiefel, can also be Unitary, Grassmannian).
  • manifold_field = ℂ: Number field type over which the manifold is defined (defaults to Complex, ℂ but can also be Real, ℝ field).
  • opt: The optimization solver function (default: quasi_Newton).
  • initial_p0 = "RS": Strategy for initial point generation ("RS": Random Split, "RE": Random Entangled, "I": Identity, or "C": Custom).
  • p0_val = nothing: Custom initial matrix on the manifold value if initial_p0 = "C".
  • kwargs...: Additional keyword arguments passed down to the optimizer and objective routines.

Returns

  • u_kij: Optimized isometry as an ITensor with primed and unprimed combined indices.
  • res: Final solver state or result object.
  • initial_objective_val: The initial objective function value evaluated at the identity matrix.
  • final_objective_val: The final objective function value evaluated using the optimized solver result.
  • elapsed_time: Total execution time for the optimization process in seconds.

Tensor Sketching based disentangler

Disentanglers.isometry_ts — Function
isometry_ts(composite_object, left_index, right_index, left_neighbors, right_neighbors; kwargs...)

Compute an optimal isometry using a fast disentangling algorithm (fastDisentangle implemented as in [1]) on a composite tensor network object across specified cuts.

Note

If the fast disentangling routine throws an exception during execution, this function falls back gracefully by returning an identity matrix for the isometry along with an error_loop flag set to true.

Note

This function is designed to be used in conjunction with apply_optimized_isometry in order to return to the original form. See examples (add reference to the example).

Arguments

  • composite_object: Composite ITensor object on which the isometry acts.
  • left_index: Left index out of the two indices on which the isometry acts.
  • right_index: Right index out of the two indices on which the isometry acts.
  • left_neighbors: Array of indices representing the left environment.
  • right_neighbors: Array of indices representing the right environment.

Keywords

  • kwargs...: Additional keyword arguments passed to internal tensor operations or solvers.

Returns

  • error_loop: A boolean flag indicating whether a fallback error recovery occurred (true if an error was caught, false otherwise).
  • u_kij: Computed isometry as an ITensor with primed and unprimed combined indices.
  • elapsed_time: Total execution time in seconds, or nothing if an error occurred.

References

This implementation is integrated into the package (as a TensorSketch module) from the following code repo as cited in the original paper: Kevin Slagle (Year). Fast Tensor Disentangling Algorithm, SciPost Phys. 11, 056 (2021). [1] fastDisentangle.

See also: isometry_ro_are, isometry_ro_sre

Environment based disentangler

Disentanglers.isometry_ev — Function
isometry_ev(composite_object, left_index, right_index, left_neighbors, right_neighbors;
            ev_original = false, manifold = Stiefel, manifold_field = ℂ,
            initial_p0 = "RS", p0_val = nothing, kwargs...)

Construct and evaluate an optimized isometry that disentangles a composite tensor network object using environment contraction methods. (Referred to as Evenbly-Vidal construction).

Note

Because this routine directly manipulates multi-dimensional arrays rather than leveraging ITensors.jl internal data structures, it is heavily optimized for performance and lower overhead.

Note

This function is designed to be used in conjunction with apply_optimized_isometry in order to return to the original form. See examples (add reference to the example).

Arguments

  • composite_object: Composite ITensor object on which the isometry acts.
  • left_index: Left index out of the two indices on which the isometry acts.
  • right_index: Right index out of the two indices on which the isometry acts.
  • left_neighbors: Array of indices representing the left environment.
  • right_neighbors: Array of indices representing the right environment.

Keywords

  • ev_original = false: Boolean flag to toggle between alternative isometry contraction orderings (F.V * adjoint(F.U) (original) vs adjoint(F.U) * F.V (optimized)).
  • manifold = Stiefel: Manifold constructor for optimization (e.g., Stiefel, can also be Unitary, Grassmannian).
  • manifold_field = ℂ: Number field type over which the manifold is defined (defaults to Complex, ℂ but can also be Real, ℝ field).
  • initial_p0 = "RS": Strategy for initial point generation ("RS": Random Split, "RE": Random Entangled, "I": Identity, or "C": Custom).
  • p0_val = nothing: Custom initial matrix value if initial_p0 = "C".
  • kwargs...: Additional keyword arguments (reserved for compatibility).

Returns

  • error_loop: A boolean flag indicating error status (false upon successful execution).
  • u_kij: Computed isometry as an ITensor with primed and unprimed combined indices.
  • elapsed_time: Total execution time in seconds.

References

The environment contraction scheme and raw array optimization techniques implemented here are based on the construction described in:

  • arXiv:2509.16439.

See also: isometry_ro_are, isometry_ro_sre, isometry_ts, isometry_ev_it

Disentanglers.isometry_ev_mat_compare_combs — Function
isometry_ev_mat_compare_combs(svd_object, left_index, right_index, left_neighbors,
                              right_neighbors, leading_u, leading_adjoint,
                              trailing_adjoint; kwargs...)

Combine and permute the U and V factors from an SVD factorization object using specified flag configurations to test and compare alternative isometric constructions that disentangle a specific network.

Note

This is a helper utility designed to systematically test different algebraic choices for the construction of the isometry from the SVD of the environment tensor. To be used along with isometry_ev_mat_env_tensor.

Arguments

  • svd_object: The SVD factorization of the environment (containing .U and .V fields).
  • left_index: Left index out of the two indices on which the isometry acts.
  • right_index: Right index out of the two indices on which the isometry acts.
  • left_neighbors: Array of indices representing the left environment.
  • right_neighbors: Array of indices representing the right environment.
  • leading_u: Boolean flag; if true, uses svd_object.U as the leading factor (false uses svd_object.V).
  • leading_adjoint: Boolean flag; if true, applies the adjoint to the leading factor matrix.
  • trailing_adjoint: Boolean flag; if true, applies the adjoint to the trailing factor matrix.

Keywords

  • kwargs...: Additional keyword arguments (reserved for compatibility).

Returns

  • u_kij: Computed isometry as an ITensor with primed and unprimed combined indices.

See also: isometry_ev_mat_env_tensor, isometry_ev
